# Project Evaluation Rubric

Every major project is scored against five dimensions before advancing to the next phase.

| Dimension | Weight | Question |
|---|---|---|
| Technical correctness | 25% | Does it perform its intended functions correctly? |
| Software design | 20% | Is it modular, maintainable, and appropriately abstracted? |
| Testing and verification | 20% | Are requirements covered by meaningful automated tests? |
| Reliability and security | 20% | Does it handle failures, invalid inputs, and security risks? |
| Engineering documentation | 15% | Can another engineer build, understand, deploy, and maintain it? |

## Passing criteria

- 80/100 overall.
- No critical security or correctness defects.
- All mandatory acceptance tests pass.
- I can explain the implementation without relying on an AI agent.

## Scoring record

Record each project's score in its own `SCORECARD.md` (see `project-template.md`) and in the Status column of `curriculum_plan.csv`.
